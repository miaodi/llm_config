# Shared Conventions

- Skills contain reusable methods; agents select skills to deliver a defined outcome.
- Load the smallest relevant set of skills. Scope boundaries do not require agent handoffs.
- Follow the user's request and project conventions over personal defaults.
- Complete authorized implementation and appropriate verification; ask only for consequential
  missing information or authorization that has not already been provided.
- Report observed results separately from assumptions and unperformed checks.
