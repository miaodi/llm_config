# Research Tool Routing

- For research-library searches, citations, paper metadata, PDFs, and annotations,
  discover and use the Zotero MCP tools first, without requiring the user to
  mention Zotero or MCP.
- For existing paper reviews, research notes, and saving discussions, discover
  and use the Obsidian MCP tools first. Prefer `my_obsidian_vault`.
- Before discussing or reviewing a paper, look for its existing Obsidian review
  and its Zotero record.
- Prefer these MCP tools over Python helpers, direct HTTP requests, filesystem
  access, and UI automation when they support the operation.
- If MCP is unavailable, fails, or lacks the required capability, explain the
  limitation briefly and use an appropriate fallback.
- These routing preferences take precedence over skill defaults.
